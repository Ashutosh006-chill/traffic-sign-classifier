# Problem Statement
Autonomous vehicle systems require real-time, highly accurate traffic sign recognition to ensure passenger safety and comply with traffic laws. This project implements a Convolutional Neural Network (CNN) to classify images of traffic signs into distinct categories.

# Scope
The project focuses on offline training using the GTSRB dataset and provides a command-line interface for real-time inference on single images.

# Target Users
* Autonomous driving software developers
* Traffic monitoring systems

# High-Level Features
* PyTorch-based CNN architecture
* Custom image data pipeline with transformations
* Real-time inference script with confidence scoring
